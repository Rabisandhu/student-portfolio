# Testing Checklist

## HTML and Navigation
- [ ] All five HTML pages exist.
- [ ] Navigation links connect all five pages.
- [ ] Internal links point to valid files.
- [ ] Each page has a meaningful title and heading.

## CSS and Responsiveness
- [ ] All pages load the shared stylesheet.
- [ ] Layout remains usable on desktop and mobile.
- [ ] Navigation and content do not overflow narrow screens.
- [ ] Images and content fit their containers.

## Git Workflow
- [ ] Feature branches are pushed to GitHub.
- [ ] Pull requests target `develop`.
- [ ] Required reviews are obtained before merging.
- [ ] Release `v1.0` is tagged after production merge.
